# 应用内搜索规范

本文档统一内置应用和官方应用的页面搜索行为。它是开发规范，不是运行时协议，也不提供搜索 SDK。

## 边界

- 搜索由当前应用自己实现，壳不提供全局搜索框。
- 壳不拦截全局 `Cmd+F` / `Ctrl+F`，不遍历官方 iframe 或内置应用 DOM。
- 应用自己负责快捷键、搜索输入框、匹配、高亮、计数、上下翻页和关闭。
- 搜索只保证当前页面已经渲染的内容；虚拟列表、分页数据和数据库中的未渲染内容不自动纳入搜索。
- 官方应用搜索实现不得依赖 Tauri IPC；内置应用可以使用自己的页面状态和已有 Tauri IPC，但搜索 UI 仍属于应用页面。

## 推荐交互

应用需要搜索时，页面内提供一个明确入口：

1. 打开搜索输入框并自动聚焦。
2. 输入时更新匹配结果；无匹配时显示清晰的空结果状态。
3. `Enter` 跳到下一个匹配，`Shift+Enter` 跳到上一个匹配。
4. `Escape` 关闭搜索并清理高亮。
5. 当前匹配使用不同于其他匹配的视觉样式，并滚动到可见区域。
6. 页面主题切换后，搜索输入框、匹配高亮和结果计数仍然可读。

应用可以根据内容类型选择实现方式：普通文本页面可以使用浏览器查找能力或自己的 DOM 匹配；编辑器、表格和虚拟列表应使用组件自身的数据和状态完成搜索。不要为了满足本规范引入跨应用通信。

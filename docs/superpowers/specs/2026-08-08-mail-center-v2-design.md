# 邮件中心 V2 设计

## 1. 目标与范围

邮件中心是 aIdea 内置的只读邮件客户端，不提供写信、回复、转发或草稿箱功能。

本次版本解决四件事：

1. 多账户通过服务商图标和未读数区分。
2. 邮件按账户隔离查看，也可以聚合查看全部账户。
3. 将远程垃圾邮件和远程已删除邮件分开显示。
4. 实时接收、断线补同步和历史拉取都有可见状态与进度。

## 2. 固定信息架构

采用经典三栏布局，参考 Apple Mail、Thunderbird 等桌面邮件客户端：

```text
左栏：全局菜单、账户和文件夹
中栏：邮件列表、筛选、批量操作
右栏：邮件详情和单封操作
```

左栏固定菜单：

```text
收件箱
  全部
  已读
  未读
垃圾箱
已删除
```

收件箱显示邮件总数；每个账户显示该账户未读数。选择账户后，中栏只查询该账户；选择“全部邮件”时聚合所有账户，但每行必须显示来源账户图标和名称。

当前版本不实现写邮件、回复、转发、草稿箱或永久删除。

## 3. 账户视觉标识

账户记录增加稳定的 `provider` 图标映射，优先使用 lucide 图标或统一的字母标记，不将远程图片作为依赖：

| provider | 默认标识 |
|---|---|
| `tencent-exmail` | 蓝色 `Q` |
| `qq-mail` | 蓝色 `Q` |
| `aliyun-mail` | 橙色 `A` |
| `aliyun-exmail` | 红色 `A` |
| `gmail` | 灰色 `G` |
| `manual` | 邮件图标 |

图标只是视觉区分，账户真实身份仍由名称和邮箱地址决定。V2 使用服务商预设图标，不额外增加图标上传或自定义配置。

## 4. 邮件文件夹与查询契约

邮件文件夹类型固定为：

```text
inbox   收件箱
spam    垃圾箱：邮件服务商自动分类的垃圾邮件
deleted 已删除：用户从 aIdea 执行删除后移动到的远程文件夹
```

账户配置分别保存：

```text
inbox_folder
spam_folder
deleted_folder
```

不同服务商的远程名称不写死在 UI 中。首次同步通过 IMAP LIST 和特殊用途标记探测；探测不到时使用服务商预设，并允许用户在账户设置中修正。

收件箱筛选使用查询参数，不复制邮件数据：

```text
account_id: 可选，指定账户
folder_kind: inbox | spam | deleted
read_state: all | read | unread
search: 可选关键词
limit / offset: 分页
```

SQLite 继续以 `account_id` 和 `folder_id` 隔离数据。聚合视图只是 `account_id = NULL` 的查询，不跨应用共享表。

## 5. 删除与已读行为

### 删除

用户在收件箱或垃圾箱中点击删除：

1. 调用 IMAP `MOVE` 将邮件移动到该账户的 `deleted_folder`。
2. 服务器不支持 MOVE 时，使用兼容的复制/标记删除流程，但不执行 `EXPUNGE`。
3. 成功后更新本地文件夹归属，邮件从原列表消失并出现在“已删除”。
4. 失败时保留本地数据，提示服务器错误，不假装删除成功。

“已删除”只读展示，V2 不提供永久删除，避免误删和不同服务商的清理策略差异。

### 已读

- 打开未读邮件时自动标记已读，并同步到远程服务器。
- 列表提供“标记为未读”操作。
- 未读邮件使用加粗主题/发件人和未读数；已读邮件使用普通字重。
- 标记失败时保留本地状态并显示错误，下一次同步重试。

## 6. 同步状态与进度

### 实时接收

每个启用账户保持 IMAP IDLE 监听。收到 `EXISTS` 或 `EXPUNGE` 事件后，只同步受影响文件夹并刷新列表计数。IDLE 断开后使用有上限的退避重连；应用恢复、网络恢复或 macOS 从休眠唤醒时执行一次增量补同步。

### 手动同步面板

顶部同步按钮只负责打开面板或触发“立即同步全部”，不再长时间阻塞整个邮件页面。面板按账户显示：

```text
账户名称 · 连接状态 · 最近同步时间
当前阶段：连接 / 读取目录 / 拉取邮件 / 写入本地
当前进度：已处理数量 / 总数量（历史拉取时显示）
错误原因和单账户重试
```

实时 IDLE 没有确定总数时显示“监听中”，不伪造百分比。手动历史拉取提供时间范围：最近 7 天、30 天、90 天和自定义；历史拉取可取消，取消后保留已写入的邮件。

## 7. 数据库变更

在 `mail-manager.db` 增加迁移，不新建第二个邮件数据库：

- `mail_accounts` 增加 `spam_folder`、`deleted_folder`，保留 `inbox_folder` 兼容已有数据。
- `mail_folders.folder_kind` 允许 `inbox`、`spam`、`deleted`。
- `mail_messages.is_read` 继续作为本地已读缓存；远程 UID 和 `account_id` 仍然不能作为全局邮件主键。
- 增加同步任务状态表，记录账户、任务类型、阶段、已处理数、总数、开始/结束时间和错误摘要；不记录密码或邮件正文。

迁移遵守现有 `docs/app-storage-spec.md`：启动前备份、事务执行、失败保留原库，不删除用户邮件数据。

## 8. 错误与安全

- 密码、授权码和 OAuth 令牌继续只存 macOS Keychain。
- 同步日志不得输出凭据、完整邮件正文或邮件附件。
- 账户连接失败只影响该账户，其他账户继续显示和同步。
- 文件夹探测失败时明确显示“未找到垃圾箱/已删除文件夹”，允许账户设置中手工选择远程目录。
- 删除和标记已读都必须在服务器操作成功后再确认本地状态，避免本地与远程不一致。

## 9. 实施顺序

1. SQLite 迁移与 Rust 查询契约：文件夹类型、账户筛选、已读筛选、同步任务状态。
2. IMAP 文件夹探测、实时事件更新、MOVE 删除和标记已读。
3. 前端 A 布局：账户图标、账户筛选、三菜单、未读状态和批量删除。
4. 同步面板：增量监听状态、历史拉取进度、日志和重试。
5. 完整测试和人工验收：多账户隔离、聚合查询、垃圾箱/已删除、断线补同步和删除失败回滚。

## 10. 验收标准

- 添加腾讯企业邮箱、QQ 个人邮箱、阿里云个人邮箱、阿里云企业邮箱后，左栏能通过图标和名称区分账户。
- 点击任一账户后，只显示该账户的邮件；点击全部邮件后显示所有账户，且列表行显示来源账户。
- 收件箱可以切换全部、已读、未读；未读数量和列表状态一致。
- 垃圾箱显示服务商自动分类的邮件；删除操作进入已删除，不会进入垃圾箱。
- 删除成功后远程网页邮箱和 aIdea 的“已删除”一致，V2 不永久清空。
- 自动接收新邮件不依赖固定五分钟轮询；断线或休眠恢复后能补同步。
- 手动历史拉取能显示账户级进度、阶段、错误和重试，不阻塞详情阅读。

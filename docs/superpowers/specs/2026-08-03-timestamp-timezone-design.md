# 时间戳转换时区支持设计

## 目标

在 DevTools 的时间戳转换工具中增加实时当前时间和时间戳展示，并支持完整 IANA 时区选择；初始值为系统当前时区。

## 范围

- 使用浏览器原生 `Intl.supportedValuesOf('timeZone')` 获取可选时区。
- 使用 `Intl.DateTimeFormat().resolvedOptions().timeZone` 作为默认值。
- 每秒刷新当前时间、秒时间戳和毫秒时间戳。
- 所选时区用于当前时间展示、时间戳转日期结果，以及日期字符串转时间戳。
- 保留时间戳转日期的 UTC 展示。
- 时区选择支持按 IANA 名称输入筛选。
- 时间戳转日期是页面唯一的高强调主操作；日期转时间戳保留为次要操作。

## 实现

修改现有 `TimestampConverter` 组件，不新增依赖或跨组件状态。组件用一个定时器维护当前毫秒值，并在卸载时清理。时区选择使用项目已有的 shadcn `Select`。

实时信息缩减为紧凑状态行，避免与转换操作争夺视觉焦点。页面采用主次两栏：左栏放置高强调的时间戳输入与转换结果，右栏保留日期转时间戳。时区输入框与筛选列表位于状态行，按时区名称实时过滤完整 IANA 列表。

日期字符串仍接受 `YYYY-MM-DD HH:mm:ss`。转换时通过 `Intl.DateTimeFormat` 计算该墙上时间在所选 IANA 时区对应的 UTC 偏移，从而生成正确的 Unix 时间戳；该逻辑应放在现有 `format-utils.ts`，供组件和测试复用。

## 验证

为时间工具补充单元测试：当前信息区渲染、默认系统时区，以及切换时区后时间戳转日期和日期转时间戳的结果。完成后运行时间工具测试、`npm run lint` 和 `npm run build`。
